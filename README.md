# 🏫 School Admission Portal

A web-based School Admission Portal developed for **Govt High School, Chikkabellikatti** to simplify and manage the student admission process through a digital platform.

## 🌐 Live Demo

**Visit Website:** [School Admission Portal](https://school-admission-portal-eight.vercel.app/)

## 📌 Project Overview

The School Admission Portal provides a centralized platform for managing student admission activities. It supports different user roles and provides separate functionalities for students, teachers and principals.

The system helps digitize admission applications, student information management and application status tracking.

## ✨ Features

- Student registration and login
- Online admission application
- Application status tracking
- Teacher login and dashboard
- Student record management
- Principal login and dashboard
- Admission application review and approval
- Document upload functionality
- Role-based modules

## 👥 User Modules

### 🎓 Student
- Register and log in.
- Submit admission applications.
- Upload required documents.
- Check application status.

### 👨‍🏫 Teacher
- Log in to the teacher dashboard.
- View student records.
- Review admission-related information.

### 👨‍💼 Principal
- Access the principal dashboard.
- Review admission applications.
- Manage admission approval activities.
